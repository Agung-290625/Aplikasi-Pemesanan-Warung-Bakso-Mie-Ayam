# Aplikasi-Pemesanan-Warung-Bakso-Mie-Ayam
 Aplikasi pemesanan makanan berbasis Android yang dirancang untuk memudahkan pengguna dalam melihat menu, memilih makanan dan minuman, serta melakukan pemesanan bakso secara praktis. Aplikasi ini menyediakan fitur daftar menu, keranjang pesanan, perhitungan total harga, pilihan makan di tempat atau dibungkus, catatan pesanan, dan riwayat transaksi
